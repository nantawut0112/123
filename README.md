# Social Scheduler Dashboard

ต้นแบบแดชบอร์ดภาษาไทยสำหรับจัดการช่องทางโซเชียลมีเดีย โดยรองรับการเพิ่มช่องทางย่อย (Sub-channels)
ได้สูงสุด 50 ช่องต่อแพลตฟอร์ม พร้อมฟอร์มสร้างโพสต์ กำหนดวันเวลาที่ต้องการเผยแพร่ และสรุปรายการที่จัดตารางไว้ล่าสุด

## โครงสร้างโปรเจ็กต์

```
.
├── index.html           # หน้าเว็บหลัก
├── assets/
│   ├── css/styles.css   # ไฟล์สไตล์หลัก
│   └── js/app.js        # ฟังก์ชันจัดการแพลตฟอร์ม/ช่อง/การโพสต์
└── package.json         # สคริปต์และการพึ่งพาสำหรับรันเซิร์ฟเวอร์ทดสอบ
```

## การติดตั้งและรันโปรเจ็กต์

โปรเจ็กต์นี้เป็นเว็บสแตติก สามารถเปิด `index.html` บนเบราว์เซอร์ได้โดยตรง แต่หากต้องการให้ทำงานครบถ้วนกับการร้องขอไฟล์แบบ module
แนะนำให้ใช้เซิร์ฟเวอร์พัฒนา (Development Server) ตามขั้นตอนด้านล่าง

1. ติดตั้ง [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป
2. ติดตั้งแพ็กเกจที่จำเป็น
   ```bash
   npm install
   ```
3. เริ่มรันเซิร์ฟเวอร์ทดสอบ
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) เพื่อใช้งานแดชบอร์ด

> หมายเหตุ: หากต้องการปรับพอร์ตหรือโฟลเดอร์ให้ดูเพิ่มเติมได้ในไฟล์ `bs-config.json` (สร้างเพิ่มได้ภายหลัง)

## การใช้งานหลัก

- เพิ่ม/ลบช่องทางย่อยได้สูงสุด 50 ช่องต่อแพลตฟอร์ม
- ใช้ฟอร์ม "สร้างโพสต์ใหม่" เพื่อเลือกแพลตฟอร์ม, ช่องทางหลายช่อง, วันที่/เวลา และสื่อแนบ
- รายการโพสต์ที่จัดตารางแล้วจะแสดงในหัวข้อ "งานที่เพิ่งวางแผน" พร้อมจำนวนช่องที่เลือกและลิงก์สื่อถ้ามี

## การพัฒนาเพิ่มเติม

- ปรับแต่งสไตล์ใน `assets/css/styles.css`
- ขยายฟังก์ชันใน `assets/js/app.js` เพื่อเชื่อมต่อกับแบ็กเอนด์จริงหรือเพิ่มการตรวจสอบข้อมูลเพิ่มเติม

## ใบอนุญาต

โปรเจ็กต์นี้จัดทำขึ้นเพื่อสาธิตการออกแบบเท่านั้น สามารถนำไปต่อยอดได้ตามความเหมาะสม
